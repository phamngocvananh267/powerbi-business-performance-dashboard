# Power BI Business Performance Dashboard
 📌 Project Overview
This project analyzes business performance by Category and Country
using simulated company data.

 🎯 Objectives
- Analyze business performance across product categories
- Compare market performance between different countries
- Support decision-making through interactive dashboards

🛠 Tools & Techniques
- Power BI
- Power Query: data cleaning and transformation
- DAX: measures and calculated columns
- Data visualization and dashboard design

📊 Key Insights
- Business performance varies significantly across categories and countries
- Certain categories dominate revenue in specific markets
- A small number of countries contribute the majority of total sales

 📁 Project Files
- Power BI dashboard file (.pbix)
- Simulated company dataset
- Dashboard screenshots

 🚀 How to Use
1. Download the Power BI (.pbix) file
2. Open it using Power BI Desktop
3. Interact with filters and visuals to explore insights
